# DECISIONS — реестр решений проекта

Реестр процессных и организационных решений. Архитектурные решения — в `ADR_SUMMARY.md`. Регистр ведётся последовательно; аннулированные/ревизованные помечены с указанием причины.

## Правила процесса (выведены из инцидентов, действуют постоянно)

| # | Правило | Из чего выведено |
|---|---|---|
| P-01 | **Правило 0:** внешние зависимости и сетевые пути верифицируются ДО правок, опирающихся на них | EJS: npm-пакета не существует — узнали до сборки, а не после |
| P-02 | Якорь правки — с уникальным контекстом; «две/три одинаковые строки» = стоп, якорь с окружением | Три инцидента: vpnmanager-16-фикс, shellcheck-вставки, кэш-монтирование легло не в тот блок |
| P-03 | Многошаговые участки — итоговым видом блока целиком | CONFIG-правки: «И в CONFIG» без якоря = неприменимо |
| P-04 | Grep-контроль (time.sleep / os.environ / CC) после каждого батча | C901 после A1; пропущенные sleep'ы в vpnmanager |
| P-05 | Shellcheck-директивы — строго перед командой/функцией | SC1126: директива после `\` ломала парсер |
| P-06 | «Нет очевидных вещей»: файл + точный НАЙТИ + полный ЗАМЕНИТЬ НА | Требование PO после батча L6 |
| P-07 | Монтирование = проверка прав владельца контейнера до прогона | PermissionError на /cache-yt: docker auto-create от root |
| P-08 | docker через sudo — каноничный workflow NAS; код живёт на D4, Fedora — транспорт | Вопрос PO «я всегда собирал через sudo» — приоритет установленного workflow над абстракциями |
| P-09 | Структурные правки — с прилагаемым выводом линтеров от меня | C901/F841 ловились после передачи PO дважды |
| P-10 | Жаргон исключён; имена режимов — официальные | «Боевой» → «обычный запуск» |
| P-11 | «Хватит торопиться» — останавливает любые подталкивания | PO: «ВАЖНО КАЧЕСТВО, А НЕ СКОРОСТЬ» |

## Реестр решений

### Реестр и коммуникация
*   **D-001…D-006:** Принят манифест взаимодействия (11 принципов: роли PO/PM/QA ↔ архитектор/разработчик; Go/No-Go до кода; 4 ветки причин на ошибку; целостные правки ≤7; Zero Unrequested Changes; CC≤9/ruff/vulture; виноват код первым). Формат правок: НАЙТИ → ЗАМЕНИТЬ НА.
*   **D-008:** Протокол секретов: значения токенов/куков/VLESS в чат не передаются. Де-факто действует с момента принятия.
*   **D-009…D-022:** Ритм аудита: приём файлов по одному, находки F-XX накапливаются, свод — по сигналу; критические — немедленно. (Процедурные, consolidированы.)
*   **D-031:** `.env` коммитится осознанно (не секрет). **Ревизия D-052:** при публичном репозитории — подтверждено построчным аудитом .env на отсутствие секретов; новые секретные переменные — только в auth/ (заигнорен).
*   **D-032:** Конвенция `_`-префикса файлов vpn/ = «выключено». **Ревизия:** hysteria-файлы изначально ошибочно названы миной; на практике Xray v26.7.28 их парсит — пул из 5 серверов подтвердил. Конвенция `_` остаётся как механизм отключения.
*   **D-033:** history/m.youtube.com.txt удалён; нормализация доменов YouTube — в youtube.com.txt.
*   **D-034:** Автоочистка: только exited-контейнеры образа проекта (ancestor-фильтр), глобальный image prune убран (F-75 — чистил чужое на хосте).
*   **D-036:** Владельцы файлов = пользователь запуска; admin-наследие исправляется по инструкции.
*   **D-037:** Политики бэкапа db/ нет — PO складывает cp-ом по необходимости; механическое решение не навязывается. Кандидат — в долгий беклог.
*   **D-039:** Git-теги/коммиты после спринтов — только по сигналу PO. **D-048:** git-момент отложен до объявления PO; строки-команды выданы по запросу, применены не были.
*   **D-046:** Никаких ручных операций с данными: система диагностирует и докачивает сама; команды диагностики (смотреть) — допустимы, данные создаёт/чинит только код.
*   **D-049:** Vulture — whitelist-подход (декларативный файл с обоснованиями), не per-line noqa.
*   **D-050:** Radon — информационная верификация CC; гейт — ruff C901 (понимает noqa по месту).
*   **D-051:** RAM 362 МБ контейнера (включая bgutil ~100-150 МБ) — принята; оптимизация «провайдер только для age-gated» не делается.
*   **D-052:** Репозиторий публичный (кроме секретов). Аудит: .env без секретов; auth/, vpn/, history/, db/, report/ — заигнорены; перед каждым push — git status контроль. Новые секреты — только в заигноренные пути.

### Архитектурно-поведенческие (подробности в ADR_SUMMARY)
*   **D-013:** yadpylesos.py прочитан полностью, аудит F-01…F-43 принят как база.
*   **D-024:** `--refresh-cache` = перестроить кэш и выйти (контракт флага).
*   **D-025:** Протокол внедрения при живой системе: останов контейнеров QA → копия файлов в backup/ → атомарная замена → py_compile → smoke.
*   **D-026:** Состав yt-dlp.conf: субтитры ru/en (с автогенерацией) → srt, обложка+метаданные, SponsorBlock все категории. Диапазон между видео 10–30с.
*   **D-027:** SIGTERM-классификация и деактивация записи при ручном запуске — отдельное обсуждение алгоритма (Q-040, отложено).
*   **D-028:** Спринт B = универсальная авторизация YouTube: куки-поток + диагностика; кейс приёмки — 18+.
*   **D-030:** `--concurrent-fragments`/`--limit-rate` — не задаются (подсказки закомментированы).
*   **D-038:** ADR-0001…0016 — контекстный слой аудита.
*   **D-043:** 18+ качается — Спринт 2В выполнен (куки + EJS + Node24 + верифицированный аккаунт).
*   **D-044:** `--temp-dir` отклонён (кросс-ФС риск EXDEV); чистка артефактов yt-dlp на старте сессии с часовым guard'ом.
*   **D-045:** Кэш yt-dlp → через XDG_CACHE_HOME (итоговое значение: /cache-yt — persistent на хосте).
*   **D-047:** Спринт 3 — защита данных (14 правок, 2 батча + оживление 3 env-ручек по выбору «Б»).
*   **D-049/D-050/D-051:** См. правила и ADR_SUMMARY (whitelist; radon-информационно; RAM 362МБ принята).

### Ревизии и закрытия находок (выборочно, ключевые)
*   **F-03:** закрыта в ходе аудита (кэш пишет process_folder; save_cache — только refresh-путь).
*   **F-14:** снята (D-024 — контракт флага).
*   **F-26:** закрыта (shutdown-цепочка run()/finally подтверждена).
*   **F-60/62/68/85:** сняты фактами (атрибут available существует; requests современный; PID 1 = python; .env PO полный).
*   **F-109:** переквалифицирована — не дефект, а принятое решение (D-031).
*   **F-118:** закрыта (состав пула VPN ожидаем).
*   **F-A:** мой дефект L3 (потеря video_attempts) — закрыт правкой L7-1; формула attempts − failed − skipped верифицирована на трёх сессиях.
*   **F-123:** телеметрия видео писала нули → закрыто S8-1 (T1–T4).
*   **F-124:** env-ручки не доходили в service-режимы → закрыто X1 (ENV_ARGS в service-блоки).
*   **F-126:** пустой ERROR при обрыве 18+ через VPN — наблюдение; `--no-continue` остаётся (решение PO); при учащении — возврат к вопросу резюма.
*   **F-127:** холодная генерация bgutil — прогрев-механизм внедрён (R-PO1); HTTP 500 холодной генерации — диагностика через bgutil_provider.log (правка выдана).
*   **F-128:** менеджер ссылок не мог сохранять (ro-монтирование) → rw-монтирование файла поверх ro-каталога; полнофункциональность подтверждена приёмкой.
*   **F-129 (косметика):** «Cookies для{domain}» — артефакт буферизации docker logs, в исходной строке пробел есть; правка не нужна, документировано (читать report/*.txt).
